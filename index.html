Kontrol Jadwal

Generate jadwal akan menyalin pola shift berdasarkan urutan tanggal periode sebelumnya. Admin tetap dapat mengedit hasilnya secara manual.

Kalender Jadwal Karyawan

Klik kode shift untuk mengubah jadwal. Perubahan tersimpan otomatis di browser ini.
Pagi (P) Siang (S) Malam (M) OFF (L / R) Cuti (C) Tanggal Merah

Rekapitulasi Jadwal Karyawan

Catatan Jadwal

P = Shift Pagi | S = Shift Siang | M = Shift Malam | L = Libur | R = OFF / Rest | C = Cuti

Warna merah menandakan hari Sabtu, Minggu, dan libur nasional. Data jadwal tersimpan pada browser/perangkat yang digunakan.

Form Request Libur Karyawan

Pengajuan akan masuk ke daftar admin dengan status Menunggu. Jadwal tidak berubah sebelum admin menyetujui pengajuan.

Daftar Pengajuan Libur

Monitoring Request per Tanggal

Menampilkan jumlah pengajuan pada tanggal yang sama untuk membantu admin mengecek potensi kekurangan personel.

Pengaturan Target OFF Karyawan

Target OFF di bawah ini merupakan acuan administrasi sesuai aturan kantor. Silakan ubah sesuai ketentuan yang berlaku. Generator menyalin pola periode sebelumnya dan tidak memaksakan jumlah OFF.
Nama KaryawanTarget OFF / Periode

Informasi Sistem

• Pola shift ditentukan manual oleh admin.
• Periode jadwal selalu tanggal 16 sampai tanggal 15 bulan berikutnya.
• Generate jadwal menyalin pola shift berdasarkan urutan tanggal periode sebelumnya.
• Request yang disetujui akan mengubah jadwal tanggal tersebut menjadi L.
• Jika tanggal request sudah memiliki jadwal, persetujuan akan mengganti kode shift menjadi L.
• Jadwal yang dikunci tidak dapat diedit atau diubah melalui persetujuan request.
• Data disimpan pada browser yang sedang digunakan.
